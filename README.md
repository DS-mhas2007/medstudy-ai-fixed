# MedStudy AI

تطبيق أندرويد لدراسة الطب: قارئ محاضرات PDF بنص حقيقي (مع OCR للصفحات الممسوحة)، مشغل فيديو مع ترجمة SRT/VTT وملاحظات بالتوقيت، مترجم ومساعد شرح بالذكاء الاصطناعي (Gemini)، مخططات Mermaid تعمل دون إنترنت، بطاقات مراجعة SM-2 مع تصدير إلى Anki، مؤقت تركيز وإحصائيات وسلسلة أيام.

## التشغيل
1. افتح المشروع في Android Studio (يتطلب JDK 11+ وتحميل AGP 9.1).
2. (اختياري) أنشئ `.env` يحوي `GEMINI_API_KEY=...`. يمكنك أيضاً إدخال المفتاح من الإعدادات داخل التطبيق؛ يُحفظ مشفراً بـ Android Keystore.
3. فعّل «السماح بإرسال النص إلى Gemini» من الإعدادات؛ بدونه لا يُرسل أي نص.
4. شغّل التطبيق. اختبارات المنطق: `./gradlew testDebugUnitTest`.

## البنية
- `core/` منطق Kotlin صرف قابل للاختبار دون أندرويد: SM-2، الإحصائيات، الترجمات، تصدير Anki، بناء الطلبات وتحليل ردود Gemini، مخططات Mermaid.
- `data/` Room (الإصدار 2 مع `MIGRATION_1_2`، ومخططات JSON في `app/schemas/`)، DataStore، الاستيراد والاستخراج، الخدمة السحابية.
- `ui/` شاشات Compose.

## طبقة إدارة الطلبات
كل طلب لـ Gemini يمر عبر `core/RequestPipeline`: كاش للأجوبة الناجحة (30 يوماً، حتى 300 جواب، مفتاحه SHA-256 على النموذج والـ prompt كاملاً)، ودمج الطلبات المتطابقة الجارية في طلب واحد، وتهدئة تلقائية عند تجاوز 10 طلبات بالدقيقة، واحترام `Retry-After`. الجداول `ai_cache` و`ai_usage` (قاعدة البيانات الإصدار 3).

## ترتيب السياق وجودة المخرجات
- `core/ContextBuilder`: يجهّز النص قبل الإرسال (حذف أرقام الصفحات والترويسات المتكررة، دمج الكلمات المقطوعة، حذف الفقرات المكررة، قص عند نهاية فقرة أو جملة).
- الشرح الأساسي لا يطلب المخطط والأسئلة والبطاقات؛ تُولَّد عند الطلب بطلب صغير مستقل (`expandSection`) ويُخزَّن في الكاش.
- `core/OutputPolish`: ينظّف المخرجات (رموز Markdown، ترقيم القوائم، تكرار، علامات الترقيم العربية، أسئلة معطوبة) قبل العرض والحفظ.
- `core/StudyNoteFormatter`: تصدير ملاحظة Markdown منسقة للمشاركة.

## ملاحظات
- أي تعديل على الجداول يحتاج رفع إصدار قاعدة البيانات وكتابة Migration (لا يوجد حذف تلقائي للبيانات).
- النسخ الاحتياطي لأندرويد يشمل القاعدة وملفات PDF، ويستثني الإعدادات (المفتاح المشفر لا يمكن استرجاعه على جهاز آخر).
- المحتوى المولّد للمراجعة الدراسية فقط وقد يحتوي أخطاء.
